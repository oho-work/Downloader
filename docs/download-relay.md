# HLS Cache Player 下载代理桥

这是可选的本机辅助程序，只转发扩展发出的清单、密钥和分片请求，不更改浏览器或操作系统代理。未启用下载代理时无需运行。

## 启动

需要 Node.js 18 或更高版本，无 npm 依赖。解压辅助程序 ZIP，在解压目录打开终端：

```powershell
node tools/download-relay.cjs
```

保持终端运行，在扩展「设置」中启用下载代理，填写现有 HTTP、HTTPS、SOCKS4 或 SOCKS5 代理地址，例如 `http://127.0.0.1:7890`。本地服务保持默认 `http://127.0.0.1:17891`。

代理需要由你自行提供；此程序本身不是 VPN 或上游代理。暂不支持代理账号密码。仅使用自己信任的代理，来源地址、请求头和媒体数据将经过该代理。

如默认端口被占用，可运行 `node tools/download-relay.cjs --port 17892`，并把扩展设置的本地服务改为 `http://127.0.0.1:17892`。本机服务只监听 `127.0.0.1`，不向局域网开放。按 `Ctrl+C` 停止。

## 故障排查

- 服务连接失败：确认 Node.js 版本、终端仍在运行，本地服务端口与扩展设置相同。
- 上游代理失败：确认代理地址、协议和端口正确，且代理可以访问资源。
- 启用代理后不会自动回退直连。关闭下载代理后，扩展恢复浏览器原有网络路径。
- 本辅助程序独立分发，不上传到 Microsoft Edge Add-ons 扩展 ZIP。
