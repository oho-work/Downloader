## 详细说明（可复制）

HLS Cache Player 用于发现网页中的 HLS 点播资源，在独立标签页播放、缓存分片，并导出为 MP4。适合整理和保存你有权访问、复制的视频内容。

播放网页视频后，扩展会显示已验证的 m3u8 资源。打开独立播放页，即可查看缓存进度、下载速度和失败分片，支持跳转播放、失败重试及缓存删除。播放页默认静音，MP4 文件名取来源网页标题。

支持标准 AES-128 HLS，包括相对密钥地址、密钥轮换和 IV；不支持绕过 DRM、付费或访问限制。直播、非 TS 分片、特殊站点鉴权及不兼容的编解码器可能无法处理；跳过失败分片的导出可能不完整。

可选下载代理仅处理扩展请求，支持 HTTP(S)、SOCKS4/5。此功能需要另行运行项目附带的本地转发脚本（Node.js 18+）；不使用代理时无需安装 Node.js。

视频缓存保存在本机，最后一个对应播放页关闭后自动清理；已导出的 MP4 保留。扩展没有遥测或开发者上传服务，资源请求仍会连接来源网站/CDN；启用代理时还会经过本地转发服务和所选代理。隐私详情见本扩展的隐私政策。

## 单一用途（可复制）

帮助用户发现网页中的 HLS 点播资源，并在独立播放器内完成播放、分片缓存和 MP4 导出；代理、缓存管理和 AES-128 处理均服务于这一视频处理流程。

## 权限理由（分别复制到对应字段）

| 权限或访问范围 | 理由 |
| --- | --- |
| `storage` | 本地保存嗅探候选、页面归属和播放标签页的会话映射，以便刷新后恢复资源提示及正确清理缓存。 |
| `webRequest` | 观察网页发起的 HLS 请求及相关请求头，识别候选清单并在后续资源请求中复用必要上下文。 |
| `tabs` | 读取当前标签页的 URL、标题和 ID，将资源关联到来源网页；创建独立播放页，并在播放页关闭或导航时清理对应任务。 |
| `alarms` | 定期检查后台任务，恢复浏览器回收后台后遗留的下载状态，并清理过期的会话上下文。 |
| `downloads` | 将用户点击导出的 MP4 保存到浏览器下载目录，并跟踪该次下载结束以释放临时对象。 |
| `unlimitedStorage` | 在扩展 IndexedDB 中缓存完整视频分片，避免普通扩展存储配额导致稍大视频无法缓存或导出。 |
| `<all_urls>` 主机权限 | 用户可能在不同网站使用 HLS，清单、密钥和分片也可能分布在不同 CDN；需要观察及请求这些资源，并连接用户选择的本机转发服务。 |
| `<all_urls>` 内容脚本范围 | 在普通网页显示已验证资源提示，并通过资源性能记录补充发现 m3u8；不注入远程脚本、不读取表单内容。 |

## 远程代码与数据披露

远程代码选项：**否**。实际使用的 hls.js、FFmpeg JavaScript、Worker 和 Wasm 随包提供，由扩展本地地址加载；网络请求取得的是清单、媒体分片和密钥，不作为代码执行。代理脚本由用户在本机运行，不从网络下载执行。

数据披露按表单当前定义勾选与实际处理相符的项目：网页 URL/标题及资源关联涉及浏览活动、媒体缓存涉及网站内容；请求上下文可能涉及 Cookie 等认证信息。**不要填写“不访问、不处理任何用户数据”或“所有数据始终不离开设备”**。开发者没有接收这些数据的后台，也没有广告、遥测、出售数据或与视频功能无关的用途；正常资源访问及可选代理传输见[隐私政策草稿](privacy-policy.md)。

## 审核测试说明（补全后复制）

无需扩展账号。使用发布者提供的合法测试页面，播放 HLS 点播视频后点击扩展图标，在嗅探列表打开播放器；确认默认静音、缓存进度、失败重试及 MP4 导出。关闭最后一个对应播放页后，缓存列表中的该视频应被清理。

代理为可选功能：在提供的项目目录运行 `node tools/download-relay.cjs`（Node.js 18+），在设置页启用代理并填写可用上游代理；本地转发地址默认为 `http://127.0.0.1:17891`。普通播放与导出可保持代理关闭。
