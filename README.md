# HLS Cache Player

HLS Cache Player 是 Chrome Manifest V3 扩展，用于发现网页请求的点播 HLS (`.m3u8`) 流，在独立标签页播放、缓存分片，并将可用的 TS 分片封装为 MP4 文件。扩展直接使用本地随附的 hls.js 和 FFmpeg Wasm 文件，运行时不依赖远程脚本服务。

**发布状态：**当前为本地 V1 候选版。随附的 FFmpeg 核心为 GPL-2.0-or-later，仓库尚未补齐公开再分发所需的第三方许可证、完整对应源码与构建材料；完成 [发布核对表](docs/release-checklist.md)前，不应将完整扩展推送为公开仓库或发布包。

## 功能

- 监听页面发起的 `.m3u8` 请求，并以页面资源记录及显示；检测到有效点播流时显示页面浮窗。刷新同一页面后，已验证的候选流可重新显示。
- 弹窗的「嗅探」页显示当前标签页、当前网址的候选流；「缓存」页显示扩展的全部视频缓存，可重新打开、单条删除或清空全部缓存。两个页面的「清空」分别只作用于嗅探结果和视频缓存，点击后立即执行。
- 独立播放页使用 hls.js 播放，后台调度并缓存分片，显示进度、速度及失败分片；支持重试失败分片和清空本次缓存。
- 支持标准 AES-128 点播流的播放与解密导出，包括相对密钥地址、密钥轮换和显式/媒体序号 IV；播放页默认静音，可通过播放器控件开启声音。
- 支持仅用于扩展的 HTTP/HTTPS/SOCKS 下载代理。
- 将已缓存的有效 TS 分片导出为 MP4，默认文件名取来源网页标题，保存到浏览器下载目录。失败或无效分片可能被跳过，导出结果可能出现时间跳跃。

嗅探仅收录通过校验的点播清单。多码率主清单按第一个子流解析、播放和全量缓存，避免导出时混合不同码率的分片。直播流、DRM、非 TS 分片、浏览器不支持的编解码器，以及需要特殊站点鉴权的资源，都不保证可播放或导出。本扩展不会绕过访问控制或数字版权保护。

## 安装

需要 Chrome 110 或兼容的 Chromium 浏览器。当前项目以源代码形式提供，无构建步骤：

1. 下载或克隆完整仓库，保留 `lib/` 下的 JavaScript 和 Wasm 文件。
2. 打开 `chrome://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
4. 修改源码后，在扩展管理页重新加载扩展，并刷新要使用的网页。

## 使用

1. 打开并播放提供点播 HLS 流的网页。页面右下角出现「检测到视频流」时，可以直接打开独立播放页；也可点击扩展图标，在「嗅探」页选择资源。
2. 在播放页观察缓存进度。全部分片可用后点击「导出 MP4」；如果只有失败分片未完成，导出时可能跳过它们。
3. 弹窗「缓存」页可查看全部缓存并单独删除，或清空全部缓存。关闭最后一个对应的播放标签页时，本次视频缓存会自动清理；重新加载播放页不会立即删除缓存。
4. 弹窗「设置」页可开关自动嗅探，调整并发、超时、重试次数及下载代理。导出格式固定为 MP4。

使用下载代理前，在项目目录运行并保持 `node tools/download-relay.cjs`（需 Node.js 18+）。设置页填写代理地址，例如 `http://127.0.0.1:7890`；本地服务默认 `http://127.0.0.1:17891`。暂不支持代理账号密码，依赖登录 Cookie 的资源可能不可用。

清空、删除等按钮不弹确认框，请在点击前确认当前页签和目标。下载文件由浏览器管理；清理扩展缓存不会删除已经保存的 MP4。

## 权限与数据

扩展使用 `webRequest`、`tabs` 和 `<all_urls>` 识别各站点的 HLS 请求、读取当前页面信息并请求清单/分片；使用 `storage`、`unlimitedStorage` 在浏览器本地保存候选流、设置、视频元数据和分片；使用 `downloads` 保存 MP4；使用 `alarms` 维持后台任务巡检。广泛的网站权限是当前全站自动嗅探实现所需，安装前请自行审查源码。

候选流 URL 和所属页面 URL 存入 `chrome.storage.local`；标题、清单 URL、分片 URL/数据与任务状态存入扩展的 IndexedDB。请求头上下文（可能含 Cookie）暂存在后台内存中，供请求资源时使用，不写入候选流持久化记录。扩展没有自建账号、遥测或上传服务；但播放和缓存会向来源网站及其 CDN 发起网络请求。启用下载代理后，本地转发服务和用户配置的上游代理会处理这些资源请求。浏览器本地仍可能残留数据，敏感来源 URL 可能包含访问令牌，请勿直接公开浏览器存储或未经处理的日志。
